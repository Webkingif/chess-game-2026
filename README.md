# Grandmaster Chess AI

Grandmaster Chess is a fully interactive, high-performance chess game built with vanilla JavaScript, HTML, and CSS. The project features a smart AI opponent powered by the Minimax algorithm with Alpha-Beta pruning for optimized decision-making.

Designed as a Progressive Web App (PWA), the game can be installed on mobile and desktop devices and runs completely offline using service workers and caching strategies.

This project focuses on algorithmic thinking, game logic implementation, and delivering a smooth, responsive user experience.

The live link is https://webkingif.github.io/chess-game-2026/index.html



---

# 🚀 Features

- AI opponent using Minimax algorithm
- Alpha-Beta pruning for optimized move calculation
- Fully playable chess game with complete rules implementation
- Offline support using Progressive Web App (PWA) technology
- Installable on mobile and desktop devices
- Smooth and responsive UI with real-time move feedback

# 🛠️ Tech Stack

- JavaScript (ES6+)
- HTML5
- CSS3
- Service Workers (PWA)
- Game Tree Algorithms (Minimax, Alpha-Beta Pruning)
